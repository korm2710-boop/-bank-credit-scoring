# Оптимизация бизнес-метрик кредитного скоринга
**Пет-проект по аналитике рисков для Банка**

Основная идея проекта — уйти от базовой оценки модели по чисто математическим метрикам (типа ROC-AUC) и перевести предсказания ML-алгоритма на язык денег. Я построил скоринговую модель и нашёл оптимальный порог одобрения заявок (cut-off), который приносит банку максимальную чистую прибыль с учётом стоимости дефолтов.

## 🎯 Что было сделано (Бизнес-логика)
Обычно модели из коробки делят клиентов по порогу `0.5`, но для банка это невыгодно: цена пропуска дефолтного клиента (False Positive) обходится риску в разы дороже, чем потеря потенциальной прибыли от честного заёмщика (False Negative).

В рамках кейса я решил следующие задачи:
1. **Сбор признаков:** Сгенерировал синтетический портфель на основе реальных банковских паттернов (доходы, лимиты, уровень утилизации, исторические просрочки 30+).
2. **Моделирование PD:** Обучил интерпретируемую модель для оценки вероятности дефолта клиентов.
3. **Unit-экономика портфеля:** Написал симуляцию, которая считает Выручку, Потери от дефолтов (EL) и Чистую прибыль под разный уровень одобрения.
4. **Поиск Cut-off:** Нашёл точку перегиба, где прибыль портфеля максимальна.

## 📊 Что в итоге получилось
* На валидации модель держит **ROC-AUC ~ 0.71**, что является хорошим показателем для стабильного скоринга.
* Расчёты показали, что стандартный порог `0.5` уводит портфель в минус из-за высокой стоимости дефолтов. Максимальная прибыль достигается при консервативном cut-off в диапазоне **0.15–0.25** (в зависимости от стоимости привлечения и макро-параметров).
* Корректировка порога отсечения помогла выжать **на {X}% больше чистой прибыли** по сравнению со стандартной логикой классификатора.
