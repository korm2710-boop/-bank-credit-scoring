
# Оптимизация бизнес-метрик кредитного скоринга & Финтех Дашборд

Финальный пет-проект по AI/ML бизнес-анализу. Проект симулирует реальный банковский кейс: переход от максимизации классических ML-метрик (ROC-AUC, Accuracy) к прямой максимизации чистой прибыли (P&L) кредитного портфеля банка.

## 🎯 Бизнес-задача
В кредитном скоринге стандартный ML-порог одобрения (`0.5`) экономически неэффективен. Ошибка **False Negative** (одобрили кредит дефолтному клиенту) обходится банку в потерю всего тела кредита, в то время как **False Positive** (отказали хорошему клиенту) приводит лишь к упущению процентного дохода. 

**Цель проекта:** Построить модель оценки рисков и найти оптимальный порог одобрения кредита (Classification Threshold), максимизирующий прибыль банка.

## 🛠️ Архитектура и Стек технологий
* **Python (Pandas, NumPy):** Генерация реалистичного банковского датасета (10,000 клиентов) с учетом риск-логики, логнормального распределения доходов и распределения Пуассона для просрочек.
* **Финтех-аналитика (WoE / IV):** Проведение разведочного анализа данных через расчет *Weight of Evidence* и *Information Value* для оценки прогностической силы факторов до обучения моделей.
* **Scikit-Learn:** Обучение Baseline-модели (Logistic Regression с регуляризацией и масштабированием признаков).
* **Бизнес-симуляция (P&L):** Написание кастомного алгоритма оптимизации финансового порога.
* **Streamlit:** Разработка интерактивного веб-дашборда для департамента рисков.

## 📈 Ключевые результаты
* Обучена интерпретируемая модель скоринга с валидационным значением **ROC-AUC ~ 0.71**.
* Доказано, что максимизация прибыли достигается при консервативном пороге одобрения в диапазоне **0.15 - 0.25** (в зависимости от макро-параметров), а не при стандартном ML-пороге `0.5`.
* Оптимизация порога позволила извлечь **дополнительную прибыль** для тестового портфеля по сравнению со стандартным подходом.

## 🚀 Как запустить дашборд локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd ai-ml-credit-scoring
```

2. Установите зависимости:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn streamlit
```

3. Сгенерируйте данные и запустите интерактивное приложение:
```bash
python data/generate_data.py
streamlit run app/dashboard.py
```
